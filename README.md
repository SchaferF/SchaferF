# Salut, je suis Florian 👋

Développeur full-stack, je construis actuellement plusieurs applications web en solo — des SaaS accessibles jusqu'à un outil métier pour la gestion de courses canines.

## 🚧 Projets en cours

### 🌐 Terres Communes — écosystème citoyen
Plateforme délibérative composée de plusieurs sous-projets indépendants, en PHP 8.5 / MariaDB, avec authentification centralisée via SSO (OIDC Authorization Code + PKCE).

- **forum-terres-communes** — Forum délibératif pour les communs : discussions structurées, cercles thématiques, réactions nuancées. SPA vanilla JS + backend PHP, PHPUnit + Playwright, CI/CD GitHub Actions. En production sur [forum.terrescommunes.com](https://forum.terrescommunes.com).
- **site-terres-communes** — Site vitrine de l'écosystème : pages éditoriales, PWA installable, panneau d'accessibilité (thème + police OpenDyslexic), back-office avec génération de synthèses éditoriales assistée par l'API Claude, notifications push. En production sur [terrescommunes.com](https://terrescommunes.com).

### ♿ Inclusa
SaaS de diagnostic et de suivi d'accessibilité web (WCAG), destiné en priorité aux PME et associations francophones. Scan automatisé via Playwright/axe-core, chiffrement des données sensibles au repos (AES-256-GCM), architecture PHP 8.5 en couches (Auth avec 2FA TOTP, invitations, gestion multi-comptes).

### 🐕 WebCaniXManager
Application de gestion de courses de canicross/CaniX : chronométrage par puces RFID (Ipico), calcul de classements et trophées, export Excel, gestion multi-sites. Architecture .NET 9 en plusieurs services (API de trophées, service de migration BDD, UI Blazor Web + application Desktop), déployée via Docker avec CI/CD GitHub Actions.

> Ces projets sont hébergés dans des dépôts privés — seuls les sites en production listés ci-dessus sont accessibles publiquement.
